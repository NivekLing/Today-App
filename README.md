# Today-App


My App Project - Today

I have an web app called today 
It's basically a productivity app that gets user to reach functions quickly. 
There are 4 tabs in this app. 
Home(Today at a glance)
Note
AI
Profile 

Home shows time date weather schedule and to-do cards. and can be added more. It mimics iOS Widget page but with more functionalities. So you can rearrange the order, add or remove cards, and when you tap on it, it shows a full view of the card. 

Note is a simple note app that taken inspiration form iOS Note app

AI is all in one AI hub chat box, that user can switch to different ai platforms and use them here. 

Profile: user profile pic and name. Follow by Apps: it's just function and settings listed here that look like a app drawer. 

These are like floating menu sitting at the bottom of the screen. It’s called Navigation Bar, short for NAV Bar

There is an extra button that only shows and reacts when certain tab is being used. I called it Extra Function. It appears right next to the NAV Bar. 
Like in AI tab, it functions as a AI model switcher. 
In Profile tab, it functions as an Edit button for changing the Profile Picture, name, and add/delete/arrange application. 
It shows up a move the NAV Bar slightly to the right to make the whole thing centered. It’s an extra round button separates from the NAV Bar. 

I designed this originally for the Anbernic RG Rotate. Since it has a square, 720x720 screen, I wanted a dashboard like at a glance view. Preferably as an app. But after a few considerations, it serve as a Web App for now. The good thing is, I also make it to work on different size of display. So it’s not limited.
